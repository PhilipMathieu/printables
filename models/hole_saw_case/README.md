# Hole saw case: print files

Generated by `python -m tools.hole_saw_case` from the measured Warrior 57523
set: 99 x 100 x 44mm closed. Each file is already in its print orientation.

| File | What | Pin |
|---|---|---|
| `coupon_filament.stl` | Hinge test coupon: print first | 34mm of 1.75mm filament |
| `coupon_steel.stl` | Hinge test coupon: print first | 34mm of 2mm (5/64in) steel rod |
| `tray_filament.stl`, `lid_filament.stl` | The case | 57mm of 1.75mm filament |
| `tray_steel.stl`, `lid_steel.stl` | The case | 57mm of 2mm (5/64in) steel rod |

Print the coupon and case for the same pin. The pin should need pressing into
the coupon's two outer knuckles and turn freely in the middle one. ASA for a
case that rides in a vehicle; PLA if it lives in a drawer. The tray wants a
brim in ASA.

These are snapshots: after changing the design, regenerate them with
`python -m tools.hole_saw_case` (add `--pin steel` or `--coupon`).
